# Void Descent / 虚空突围

一个面向浏览器的原创 survivor-like / action roguelite 项目。

## 项目目标

我们不追求“最快做完”，而是把它长期打磨成一个：
- 操作清晰、手感稳定；
- 构筑具有明显质变；
- Boss 和敌人真正改变走位；
- 画面在高强度战斗下仍然保持审美一致；
- 随机截取一帧也尽量具有“壁纸感”；
- 能稳定运行在桌面端和移动端浏览器；
- 可以通过 GitHub + Render 持续部署迭代的作品。

## 当前阶段

项目处于 **Pre-production / Vertical Slice Foundation**。

第一阶段不会盲目堆几十种武器，而是优先完成：
1. 可维护的项目结构；
2. 统一的视觉语言；
3. 战斗与移动手感；
4. 数据驱动的武器/升级系统；
5. 一套真正可玩的精英与 Boss；
6. 性能预算与移动端适配。

## 部署

目标为 Render Static Site。根目录保留 `render.yaml`，每次推送到 GitHub 后可以继续用于自动部署。

## 原创原则

可以研究公开的 survivor-like / roguelite 游戏机制与设计方法，但不会复制已有游戏的角色、美术、音乐、剧情文本、地图、UI 素材或具有辨识度的独特表达。最终内容与视觉资产应保持原创。
